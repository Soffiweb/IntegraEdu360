# Catálogo de especialidades

`database/seeders/EspecialidadSeeder.php` incluye Bachillerato en Ciencias y las 34 figuras profesionales de Bachillerato Técnico de la reforma MINEDEC-MINEDEC-2025-00051-A, artículo 2 (16 de octubre de 2025).

Fuente oficial: https://educacion.gob.ec/wp-content/plugins/download-monitor/download.php?force=1&id=23072

Los códigos son identificadores internos de IntegraEdu360, no códigos ministeriales. Se mantienen BGU y BTE para conservar referencias existentes.

El seeder completa el catálogo por institución, conserva IDs y estados existentes y puede ejecutarse varias veces. Las figuras previas o personalizadas permanecen para conservar sus asociaciones. La oferta autorizada de cada institución debe configurarse según su autorización; disponer del catálogo no implica autorización para impartir todas las figuras.

No incluye el catálogo independiente de Bachillerato Técnico Productivo.
